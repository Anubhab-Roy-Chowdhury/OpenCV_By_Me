# OpenCV_By_Me

A collection of real-time computer vision projects using OpenCV in Python.  
Includes face, eye, and smile detection, shape detection, and other experiments for learning and practical applications.

---

## Topics
python opencv computer-vision face-detection smile-detection eye-detection real-time projects

---

## Features
- Real-time face detection using Haar cascades
- Eye detection within detected faces
- Smile detection within detected faces
- Shape detection and other computer vision experiments
- Optimized for learning and experimentation
