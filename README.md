# OpenCV_By_Me 📷🤖

## About
This repository contains my computer vision projects and experiments using OpenCV in Python. It features real-time face detection, eye detection, smile detection, shape detection, and various other computer vision applications. The projects demonstrate practical implementations of OpenCV for image and video processing.

---

## Topics
python opencv computer-vision face-detection smile-detection eye-detection real-time projects image-processing video-processing

## Key Features
- Real-time face detection using Haar cascades
- Eye detection within detected faces
- Smile detection within detected faces
- Basic structure drawing (lines, circles, rectangles, text)
- Edge detection using Canny and other algorithms
- Image filtering and blurring techniques
- Contour detection and analysis
- Video processing and frame capture
- Shape detection experiments
- Optimized for learning and practical experimentation

---

## Setup/Usage
1. Clone the repository:  
   ```bash
   git clone https://github.com/Anubhab-Roy-Chowdhury/OpenCV_By_Me.git
   ```

2. Navigate to the folder:
   ```bash
   cd OpenCV_By_Me
   ```

3. Install required packages:
   ```bash
   pip install opencv-python numpy
   ```

4. Run the Python scripts:
   ```bash
   python script_name.py
   ```
   
5. Press `q` to exit real-time detection windows
